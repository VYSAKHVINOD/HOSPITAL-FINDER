Hospital Finder - Troubleshooting Guide

Common Issues and Solutions

1. Check if PHP is Working

Create a file called test.php in your project folder with this content:

<?php echo "PHP is working!"; ?>

Access it in your browser: http://localhost/your-project-folder/test.php

2. Check Database Connection

Test your database connection with this code:

// db_test.php
<?php
$host = 'localhost';
$dbname = 'kerala_hospitals';
$username = 'root';
$password = '';

try {
  $pdo = new PDO("mysql:host=$host;dbname=$dbname", $username, $password);
  echo "Database connection successful!";
} catch (PDOException $e) {
  echo "Connection failed: " . $e->getMessage();
}
?>

3. Check API Endpoints

Test if your API endpoints are working:

// Test hospitals API
http://localhost/your-project-folder/api/get_hospitals.php?district=Thiruvananthapuram
// Test hospital details API
http://localhost/your-project-folder/api/get_hospital_details.php?id=1

4. Check JavaScript Console for Errors

Open your browser's developer tools (F12) and check the Console tab for any errors.

5. Verify File Structure

Ensure your project has the correct file structure:

  • Project folder contains index.html, script.js, style.css, db_connection.php
  • API folder exists with get_hospitals.php and get_hospital_details.php
  • All file names are spelled correctly

6. Check Database Content

Make sure your database has data:

// Check if hospitals table has data
SELECT COUNT(*) AS count FROM hospitals;

Debugging Steps

Enable Detailed Error Reporting

Add this to the top of your PHP files to see detailed errors:

<?php
error_reporting(E_ALL);
ini_set('display_errors', 1);
// Rest of your code...
?>

Check File Permissions

Ensure your PHP files have the correct permissions (usually 644).

Verify Database Credentials

Double-check your db_connection.php file has the correct database credentials.
